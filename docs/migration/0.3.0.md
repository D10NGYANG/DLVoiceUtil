# 从 0.2.x 升级到 0.3.0

0.3.0 修复录放音状态、资源释放和 PCM 数据处理，并升级 Kotlin Multiplatform 工具链。升级前先确认消费方能够使用 Kotlin 2.4.21 元数据和 Android compileSdk 37。

## 依赖与平台

```kotlin
implementation("com.github.D10NGYANG:DLVoiceUtil:0.3.0")
```

仓库配置见 [安装说明](../../README.md#安装)。提供 KMP 根模块、Android、iOS arm64 和 iOS simulator arm64 制品；旧版制品保留。

- Android `minSdk` 仍为 26，`compileSdk` 至少为 37；提高 `compileSdk` 不等于提高 `targetSdk`。
- Kotlin/Compose Compiler 建议对齐 2.4.21；DLCommonUtil 1.1.0、Coroutines 1.11.0 随依赖元数据解析，避免 force/strictly 锁定旧版本。
- 仅使用本库不需要引入示例使用的 DLAppUtil、Compose 或 Lifecycle。
- 库 JVM 字节码目标仍为 8，示例为 11。构建 Gradle 的 JDK 与产物字节码目标是不同设置。

## API 与行为

| 场景 | 0.3.0 行为 | 调整建议 |
|---|---|---|
| 停止录音 | 新增 `suspend stopAndGetData()`，等待采集退出及原生资源清理后返回 PCM | 在界面协程中使用新方法 |
| 同步 `stop()` | 方法保留，但现在等待停止完成 | 避免在 UI 线程处理长录音 |
| 重复 `start()` | 同一实例运行期间再次启动抛出 `IllegalStateException` | 根据状态控制按钮，完成停止后再重启 |
| 非法播放参数 | 空数据、奇数字节或非正采样率立即失败 | 调用前检查有效 PCM；设备仍可能拒绝不支持的正采样率 |
| 异步失败 | `getErrorFlow()` 暴露错误并复位运行状态，后续可重新启动 | 收集错误；不要只依赖状态 Flow 判断成功 |
| 音量显示 | 统一输出 0–1 比例 | 移除旧百分比/放大倍数换算，按新范围显示 |
| 时长 | 按累计有效样本计算，修正非整千采样率的截断误差 | 不依赖旧版错误时长进行业务计算 |
| Android 部分读取 | 仅保留 read 返回的有效样本 | PCM 不再包含缓冲区尾部旧数据 |
| iOS 会话 | 每段录音独立通道，清理 StableRef/AudioUnit；通道溢出显式失败 | 不依赖跨会话残留数据或静默丢帧 |

旧 Android `PCMPlayer`、`PCMRecorder` 保持弃用状态，推荐使用 `createPCMVoicePlayer()` / `createPCMVoiceRecorder()`。iOS 旧类名保留；`PCMVoiceRecorderIOS` 复用修正后的 RemoteIO 实现。

## 示例工程迁移

- Android APK 构建入口从 `:composeApp:assembleDebug` 改为 `:androidApp:assembleDebug`。
- Android 入口、Manifest、启动资源移动到 `androidApp/src/main`；包名保持 `com.d10ng.voice.demo`。
- `composeApp` 保留共享界面及 Android actual 实现，iOS framework 名称仍为 `ComposeApp`。
- Android 库测试任务改为 `:DLVoiceUtil:testAndroidHostTest`。
- KMP 库使用 `com.android.kotlin.multiplatform.library`；Android 应用插件与 KMP 模块分离。
- DLAppUtil 3.0.0 仅供示例使用。示例完善权限拒绝、保存结果和页面退出时的资源清理。

## 建议回归

验证权限拒绝/重试、录音停止后立即重启、自然播放结束、44.1 kHz 时长、空/奇数字节输入、页面退出及后台停止。使用 iPhone 的项目另测音频路由和通话中断。

已执行的测试及已知限制见 [发布说明](../releases/0.3.0.md)。
