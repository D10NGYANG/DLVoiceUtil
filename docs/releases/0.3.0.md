# DLVoiceUtil 0.3.0

发布日期：2026-11-04。

本版本修复 Android/iOS PCM 录放音的数据和生命周期问题，增加可等待停止的录音 API，并完成 AGP 9 与新版 Kotlin Multiplatform 工具链升级。

## 安装

```kotlin
maven("https://raw.githubusercontent.com/D10NGYANG/maven-repo/main/repository")

// KMP commonMain
implementation("com.github.D10NGYANG:DLVoiceUtil:0.3.0")
```

[完整安装说明](https://github.com/D10NGYANG/DLVoiceUtil/blob/v0.3.0/README.md) · [从 0.2.x 升级](https://github.com/D10NGYANG/DLVoiceUtil/blob/v0.3.0/docs/migration/0.3.0.md)

## 主要变更

- 新增 `stopAndGetData()`，停止录音时等待采集任务与原生资源清理，减少快速重启竞争。
- 新增错误 Flow，启动/采集失败后复位状态，允许后续重试；统一重复启动和 PCM 输入校验。
- 录音按块累积，避免每帧复制全部历史数据；修正小端符号转换和非整千采样率时长。
- Android 仅追加有效读取样本，完善取消与 AudioRecord/AudioTrack 释放。
- iOS 修复 StableRef 泄漏、跨次录音通道复用、异步停止竞争、播放尾帧及旧 WAV 采样率；检查原生初始化错误。
- 增加 Apple Silicon iOS 模拟器目标，Android 应用拆为独立 `androidApp`，KMP 库采用官方 Android-KMP 插件。
- 升级 DLCommonUtil 1.1.0、示例 DLAppUtil 3.0.0，移除无用 Okio/ViewModel 声明及版本检查插件。

## 升级要求

- Kotlin 元数据基线 2.4.21；Android minSdk 26、compileSdk 至少 37。
- 库 JVM 字节码目标仍为 Java 8；示例 targetSdk 仍为 34。
- 同步录音 `stop()` 保留，但现在等待清理；界面协程推荐 `stopAndGetData()`。
- 运行中重复 `start()` 会抛异常，音量事件范围为 0–1；具体迁移见升级说明。

## 验证范围

- Android 主机测试 10 项、iOS 模拟器测试 12 项通过。
- Android debug/release 构建、lint，以及独立 Maven 消费工程的 Android/iOS 双架构编译通过。
- 华为手机完整录音、保存、播放、连续启停和后台停止流程通过。
- iOS 26.5 模拟器完整应用 XCTest 连续两次通过。

## 兼容性与限制

构建组合为 Gradle 9.8.2、AGP 9.3.1、Kotlin 2.4.21、Compose Multiplatform 1.12.2，测试使用 Xcode 27.2。Gradle 与 Xcode 超出 Kotlin 当前官方完整支持矩阵列明的版本范围，以上结论限于本次验证环境。

此前出现的模拟器 AudioUnit 初始化 RPC 超时未在升级后的两轮应用测试中复现，尚不能确认其根因或长期稳定性。未覆盖 iPhone 真机、蓝牙/通话中断和长时间压力测试。录音仍保存在内存，业务应限制时长。
